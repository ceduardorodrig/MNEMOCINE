# Crafty Controller

Minecraft server management panel and orchestration daemon.

**Server:** kavure  
**Admin Port:** `8444` (host `8444` → container `8443`)  
**Game Port:** `25565`  
**URL:** `https://kavure.chimaera-heptatonic.ts.net:8444`  

> **✅ Migrated to Kavure (08/08/2026 — Phase C1):** Crafty + Dominium server (Minecraft 1.21.1/Fabric) migrated from psicopompo using **rsync `--checksum` (0 differences)**. **Backups (AdvancedBackups) now route directly to NAS** via NFS (`/srv/data/minecraft/offbox` → `/mnt/BACKUP/minecraft-server-kavure/`), aligning with the Zomboid design pattern. JVM configured with **G1 flags** (2G floor / 8G ceiling / 5G soft target) to coexist smoothly with Zomboid. psicopompo remained intact (Crafty stopped, zero deletions).  
>  
> **Backup Cadence (13/09/2026):** AdvancedBackups writes to `/minecraft-backups` (= offbox → NAS) every 2 hours **strictly while the server process is running**. When the server is stopped, automatic runs idle as expected.

> **🔄 Modpack & Loader Update (06/10/2026):** The server was resynchronized with Prism Launcher's **Dominium** instance (psicopompo), which received a major overhaul on 06/10. **Fabric Loader 0.18.4 → 0.19.5** (mandatory requirement: `fabric-language-kotlin 1.14.1` requires `>=0.19.5` and `puzzleslib 21.1.62` requires `>=0.19.0`). Synchronization executed **by `id` in `fabric.mod.json`** (never filename matching) while **excluding `environment: "client"`**: **33 shared mods updated**, `armor_model_api` **added** (new dependency for `archers/paladins/rogues/wizards` 3.1.3), 118 orphan `.pw.toml` files and 2 client-only mods (`libIPN`, `reflex`) purged. Final state: **103 jars on server × 111 on client → 77 shared across identical versions** (strict parity), with 33 client-only and 24 server-only by design. Boot verified in sandbox (`Done`, 256 mods) and on live server (`Done (205s)`, 257 mods; SLP probe `:9095` → HTTP 200 "up"). Pre-update backup: `/srv/data/minecraft/pre-update/20261006/` (mods/config, 459 MB) + offbox archive `offbox/archive/pre-update-20261006/` (world state, 37 GB / 12,427 files). See [[dominium-permissions]].  
>  
> **Backup Resumed (06/10/2026):** Server resumed active execution → **AdvancedBackups** writes 2-hour snapshots to `/minecraft-backups` (offbox → NAS).  
>  
> **⚠️ Deprecated Packwiz Distribution (06/10/2026):** The repository `ceduardorodrig/DOMINIUM-MODPACK` and GitHub Pages manifest respond **404**. Client modpack distribution is managed via **`.mrpack`** archives generated by `export_mrpack.py`, located **in the server directory on kavure** alongside management utilities — see [[dominium-permissions]].

> **Distant Horizons 3.3.3 (06/10/2026):** DH deployed on **both sides** (matched version — official recommendation). The server initializes `DhServerLevel` per dimension, **integrates with C2ME**, and **generates/stores LODs**, serving them to connected clients (client log: `Level init received` + `Rate limited by server … Sync on login rate limit`). Overworld database on server: **4.2 GB**. Generator operates in `FEATURES` + `SURFACE_THEN_CHUNKS` mode (fast generator: multithreaded vanilla chunk generation, extracts LOD and **discards** chunk; `INTERNAL_SERVER` is the slower alternative). ⚠️ DH reset its internal server configuration during migration (3.2.0 → 3.3.3 lacks config migration), reverting `levelKeyPrefix` to **seed hash** → client LOD cache changed active hash keys. Harmless regenerable cache. ⚠️ Benign error `IllegalStateException: Chunky is not loaded` resolved on 06/10/2026 by removing Chunky (DH 3.3.3 provides native pregeneration via `/dh pregen`).

> **Tooling & Housekeeping (06/10/2026):** Dominium management tools are consolidated in `/srv/data/minecraft/minecraftserver [dominium]/` (`client-push.sh`, `sync_mods.py`, `export_mrpack.py`, `README.md`) — see [[dominium-permissions]]. The 37 GB pre-update archive on NAS was cleaned up once rollback parity was confirmed; the local 459 MB snapshot (`/srv/data/minecraft/pre-update/20261006/`) was retained.
